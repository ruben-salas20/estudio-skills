# Escribir una forma nueva

Una forma dice cómo se cuenta un vídeo: la estructura, el papel de cada plano y cuándo se usan palabras. No dice cómo se ve (eso es el estilo). Modelo: `formas/relevo.md`.

Formas que aún no existen y que se escribirían así cuando hagan falta:

- **Anuncio:** gancho en los primeros 2 s, problema, solución con el producto, prueba y llamada a la acción.
- **Loop:** sin historia; el último fotograma encaja con el primero para repetirse sin corte.

## Qué debe fijar

1. **Para qué sirve y para qué no**, en una frase cada cosa, para elegir la forma sin dudar.
2. **Estructura:** las partes en orden, qué hace cada una y cuánto dura, en segundos o como proporción del total.
3. **Palabras:** si lleva texto, voz o ninguno, y cuántas palabras admite cada parte.
4. **Guion:** qué escribe Claude por cada plano y cuándo el guion está hecho.
5. **Revisión de los cortes:** qué tiene que continuar de un plano al siguiente.

## Cómo probarla

Escribe el guion de un tema de prueba con la forma nueva y enséñaselo al usuario antes de construir nada. Una forma está probada cuando el usuario reconoce en el guion la estructura que pidió.
